# AI 启动指令模板

复制以下内容给你的 AI 智能体，然后附上自己的已读书单。

```text
请接管我的《读书小记》制作项目。

首先读取此项目的 skill/SKILL.md，以及 Skill 指定的模板和 QC 文档。
严格使用仓库已经锁定的视觉/工程体系，不重新设计。

我会提供自己的已读书单。请按以下顺序执行：
书单整理 → 权威书目 CURRENT → 内容字段 → 真实封面 → 黄金样页 → 批量正文 → 前置页/目录 → 外封 → 总装 → QC → PRINT READY。

执行规则：
- 不确定就 HOLD，不猜；
- 不用 AI 生成图冒充真实出版封面；
- 用户个人感想不得代写成“用户本人观点”；
- 黄金样页未 PASS 不批量生产；
- PASS 后冻结，局部问题局部修复；
- 目录必须从最终书目与页码生成；
- 最终 QC 未通过不得称为正式打印版；
- 尽量自主推进，把多个需要我确认的问题汇总后一次询问。

现在先接收我的书单，只完成书单整理与 CURRENT，不要跳阶段。
```
