# 实物打印验证总结｜从屏幕稿到真正拿在手里的书

> 状态：V0.7  
> 本文整理自原版《读书小记》的真实打印样张与成品观察。重点区分“早期样张暴露的问题”和“修正后实际 PASS 的结果”，避免把踩坑误写成最终规范。

## 一、最终实物总体结论

修正后的 VOL.01 内页实物打印整体成立：

- 米白/奶油纸与版式搭配自然；
- 正文字号体感舒适；
- 装订中缝安全；
- 页码位于阅读外侧；
- 背面存在轻微透字，但实际阅读中不构成明显干扰。

因此，“干净数字底稿 + 实体米白纸提供最终暖色与纸感”的路线得到实物验证。数字文件没有必要再额外模拟泛黄、复古纸纹和假纸张阴影。

## 二、早期实物样张发现过什么问题

### 1. 目录视觉偏小

早期实物中，002/003 目录主体相较正文显得偏小、视觉密度不足。

后续判断：偏小仍可阅读，但它提醒我们——屏幕上“能看清”不等于印到实际尺寸后层级就合适。

**永久规则：**目录必须以真实尺寸观察，不仅依靠手机/电脑预览。

### 2. 目录页码与全册页码视觉不统一

实物暴露出目录页码与正文页码大小体系不一致。

**永久规则：**前置页不能作为孤立设计；页码属于全册统一系统。

### 3. 非黄金母板页面曾出现文字失真/发糊

早期样张中，除已采用新设计参数的黄金页外，一批旧页面出现明显文字发糊、像复印件的感觉，文字边缘不够干净。

这不是“纸张天然效果”，而是旧页面没有同步到新的生产参数。

**永久规则：**
- 黄金母板 PASS 后，批量页必须继承同一生产参数；
- 不允许只把少数样页升级高清，而其余页面继续沿用旧低质量渲染；
- QC 必须抽查普通批量页，而不是只看最好看的黄金样页。

### 4. 书封曾出现失真与“贴图感”

早期打印中，部分书封不像高清原图自然融入页面，出现失真或低清贴合感。

**永久规则：**
- 页面整体高清不能弥补源书封低清；
- 真实封面需要在实际打印尺寸检查清晰度；
- 不应为了铺满区域拉伸封面。

### 5. 页眉/页脚彩蛋灰度曾过轻

屏幕上可见的浅灰彩蛋，在实物打印后出现难读现象。

**永久规则：**浅灰细字、细线必须经过实物验证。屏幕显示器的发光效果不能代表纸面反射效果。

## 三、哪些页面证明模板本身成立

早期实物观察中，001、005、006 等页面的字号、留白、横线和图片关系总体成立，没有发现明显自动缩放、跑位、裁切侵入正文或打印方向错误。

这说明问题主要来自“批量生产参数没有统一”，而不是黄金版式本身需要推倒重来。

## 四、外封实物观察

外封平铺样张整体 PASS：

- 中线位置正确；
- 正封与封底主要图文没有被中缝吞掉；
- 封底视觉相对更疏，与正封形成呼应；
- 米白实体纸会自然压低复古拼贴的饱和度；
- 不模拟假书脊后，实际折痕和实体纸张本身提供了更自然的“书”的感觉；
- 整体留白使成品更接近独立刊物，而不是一张铺满元素的海报。

**永久规则：**屏幕稿不要为了“像一本旧书”而过度制作假纸张、假折痕和假书脊；真实材料会完成其中很大一部分视觉工作。

## 五、套页与装订的真实验证

实物套页曾用连续页进行验证，025/026 的实际前后关系正确，证明当时的套页顺序成立。

120 页书芯在内层出现纸边逐渐外凸/爬移，是多页折叠装订的正常物理现象，不应把它误判为每一页都必须重新裁齐的页面设计错误。

**永久规则：**
- creep（爬移）属于最终拼版/装订层问题；
- 不因书芯物理爬移反向修改已经 PASS 的单页正文母版；
- 装订前应把书芯压紧、固定后再执行最终装订/裁切。

## 六、屏幕与纸面最重要的差异

实际项目验证了至少四类屏幕无法可靠替代的判断：

1. **字号体感**：屏幕放大查看会掩盖实际尺寸偏小。
2. **浅灰可读性**：屏幕能看见，纸面可能太淡。
3. **图片清晰度**：屏幕小图看似正常，打印后低清和失真更明显。
4. **纸张对颜色的影响**：米白纸会改变饱和度、对比度和整体温度。

因此，重要版本至少需要一次小批量实物测试。

## 七、推荐的实物测试页

不必第一次就打印整册。测试页应覆盖：

- 001 或其他前置页；
- 目录页；
- 黄金正文页；
- 一张普通批量正文页；
- 含浅灰页眉/页脚的页面；
- 含彩色真实书封的页面；
- 一组连续奇偶页；
- 外封正反面。

这样可以同时暴露“设计问题、批量生产问题、打印参数问题和装订问题”。

## 八、判断问题属于哪一层

看到实物问题时，先分类：

**模板层**：所有页面都存在同类版式问题 → 修改模板。

**生产层**：黄金页正常、普通批量页异常 → 修正批量生产参数，不推翻模板。

**素材层**：只有某些书封模糊 → 更换/改善该素材，不重做整页体系。

**打印层**：数字文件正常但打印缩放/灰度异常 → 调整打印参数。

**装订层**：爬移、中缝、折叠问题 → 在最终拼版/装订层处理。

这是原项目最重要的经验之一：**先定位问题属于哪一层，再做最小范围修改。**
