# 读书小记｜Reading Notes Skill

> 把一份“已读书单”交给 AI，复用一套经过真实印刷验证的设计与生产流程，制作属于自己的《读书小记》。

## 项目目标

这不是单纯的页面模板，而是一套面向“人 + AI 智能体”的可复制制作系统。

目标是让使用者主要提供自己的已读书单，由 AI 按固定的视觉、内容、印刷与 QC 规则完成：书单整理 → 页面生产 → 目录 → 封面/封底 → 总装 → 印前检查 → 打印交付。

项目源自两批已经实际制作并打印的《读书小记》。公开版会沉淀经过验证的设计规则、踩坑经验、打印经验和必要示例；不会把原始生产目录或第三方书籍封面素材库直接公开分发。

## 使用方式（目标形态）

使用者准备自己的已读书单，将本项目的 `skill/SKILL.md` 与模板资产交给支持文件读取/生成的 AI 智能体，然后提出：

> 这是我的已读书单，请按照《读书小记》Skill 制作我的 VOL.01。

AI 应先校验输入，再按 Skill 的阶段门推进；遇到缺失封面、内容不确定或工程异常时进入 HOLD，而不是猜测或偷偷替换。

## 公开原则

- 公开我们自己的设计规则、工作流、模板结构、QC 方法和实际经验。
- 实物照片在确认适合公开后加入。
- 第三方书籍封面、出版物内容等不作为素材库重新打包分发。
- 示例尽量使用自制、可授权或仅用于必要说明的材料。
- 已经 PASS 的生产结果不因重复运行而被无意义重做。

## v1.0 验收标准

让一位没有参与原项目制作的人，仅依靠本仓库和自己的书单，在 AI 智能体辅助下完成一本保持同一视觉体系、但内容属于自己的《读书小记》，并通过最终印前 QC。
