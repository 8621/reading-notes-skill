# 打印与装订指南｜V0.3

## 已验证工程路线

- 源单页：143 × 208 mm。
- 裁切目标：140 × 205 mm。
- A4 横向双拼输出。
- 手机打印/普通打印时使用 **实际尺寸 / 100%**，禁止“适合页面”自动缩放。
- 上下中央可保留极小裁切标记。
- 高清优先；需要控制文件大小时宁可分包，不通过降低清晰度解决。

## 双面与页序

成品物理正反关系为 001↔002、003↔004、005↔006……；但 A4 同板组合不等于成品物理正反。不要只凭屏幕拼版顺序判断双面关系。

全册输出前先用少量页面做实物测试，确认双面方向、裁切和装订侧。

## 装订策略

历史项目最终形成的重要原则是：**装订属于最终输出层，不反向修改已经 PASS 的高清内页母版。**

骑马钉路线：整册页 → booklet 拼版 → creep（爬移）检查/必要补偿 → 实物测试 → 打印分包。

如果某种装订方式实测失败，只调整最终拼版/装订输出，不返工已经通过的正文母版。

## 给打印执行者的简版说明

> 请按 100% 实际尺寸打印，不要自动适合页面或缩放。保持原文件清晰度与双面方向；先打印少量测试页确认正反、裁切和装订方向，再进行全册输出。

## 实物检查

测试页至少观察：纸色、透印、细灰线可见度、彩色书影、双面定位、裁切精度、装订后内侧安全距离。

本文件后续会加入真实打印照片及照片标注。
