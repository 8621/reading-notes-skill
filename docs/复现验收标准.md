# 复现验收标准｜V0.6

## 目的

验证这个项目是否真的“可复制”，而不是只有原作者和原 AI 才看得懂。

## 测试对象

优先选择一位没有参与原版制作的人，并使用：
- 一份新的已读书单；
- 一个新的 AI 对话/智能体；
- 本 GitHub 仓库；
- 不依赖原项目聊天历史。

这正是项目最终要服务的真实场景。

## Level 1｜启动成功

PASS 条件：
- 使用者能从 README 找到 START_HERE；
- AI 能定位并读取 SKILL；
- AI 没有直接跳到整册生成；
- 能把原始书单整理成权威书目 CURRENT；
- 不确定项能进入 HOLD。

## Level 2｜黄金样页成功

至少测试：
- 1 本短中文标题；
- 1 本长标题；
- 1 本含外文/英文信息的书；
- 1 个与黄金母板比例明显不同的真实书封。

PASS 条件：
- 页面仍保持黄金模板结构；
- 没有因个别长内容重设计整页；
- 真实书封没有被 AI 假封替代；
- 装订侧、页码外侧逻辑正确；
- 用户肉眼认为“这是同一套《读书小记》”。

## Level 3｜小批量成功

建议先生产 8–12 本，而不是第一次就做完整书单。

PASS 条件：
- 每页与 CURRENT 一一对应；
- 没有串书、重复、漏页；
- PASS 页面没有因后续单页修复被无意义重做；
- HOLD 能单独解决；
- 目录能从冻结页码生成。

## Level 4｜整册成功

PASS 条件：
- 前置页、目录、正文、外封均完成；
- 页码连续且目录一致；
- QC 全部 PASS 或存在明确 ACCEPTED DEVIATION；
- HOLD = 0；
- 输出唯一、明确的最终打印候选。

## Level 5｜实物打印成功

建议先做少量双面样张，再整册打印。

观察：
- 纸色与屏幕预期差异；
- 文字可读性；
- 细灰线是否过淡；
- 彩色书封效果；
- 透印；
- 双面方向；
- 裁切；
- 装订后内侧安全距离；
- 封面/封底整体效果。

实物问题应记录到“踩坑记录”，并决定是：
1. 修改数字模板；
2. 只修改打印参数；
3. 只修改最终拼版/装订层；
4. 记录为可接受差异。

不要未经判断就反向重做正文。
