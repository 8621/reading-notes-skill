# QC 检查清单｜正式打印前

> AI 必须逐项检查并记录 PASS / HOLD / ACCEPTED DEVIATION。

## A. 文件完整性
- [ ] PDF 可正常打开、解析，未损坏
- [ ] PDF 无意外加密/权限限制
- [ ] 总页数与权威页码清单一致
- [ ] 页面顺序正确
- [ ] 无缺页
- [ ] 无重复页

## B. 页面工程
- [ ] 正文页面尺寸符合项目规范（当前基准 143 × 208 mm）
- [ ] 外封尺寸/出血符合当前工程规范
- [ ] 奇偶页装订方向正确
- [ ] 重要内容未进入装订危险区
- [ ] 页码位于正确外侧位置

## C. 内容映射
- [ ] 每一页书名与权威书目一致
- [ ] 作者/版本信息不存在明显串页
- [ ] 真实书封与该书对应
- [ ] 目录与正文页码对应
- [ ] 无上一页/旧模板文字残留

## D. 视觉
- [ ] 书名无不可接受的溢出
- [ ] 正文无截断
- [ ] 图片未异常拉伸
- [ ] 页面层级与黄金模板一致
- [ ] 无突然出现的不同字体/字号/边距体系

## E. 状态
- [ ] 所有 HOLD 已解决
- [ ] 所有 ACCEPTED DEVIATION 有明确记录
- [ ] 最终候选文件版本唯一、命名清楚

全部满足后方可标记：**PRINT READY**。
