# SKILL.md — 读书小记生成 Skill

> 版本：V0.5  
> 目标：用户主要提供自己的已读书单，AI 按本仓库已验证的视觉与工程体系，生产一本内容属于用户自己的《读书小记》。

## 0. 先读这些文件

执行本 Skill 时，按需读取：
1. `templates/booklist/已读书单模板.md`
2. `templates/page/黄金正文页规范.md`
3. `templates/page/前置页与目录规范.md`
4. `templates/cover/外封黄金规范.md`
5. `docs/整册结构与页码规则.md`
6. `docs/制作流程.md`
7. `docs/踩坑记录.md`
8. `docs/印刷指南.md`
9. `docs/QC检查清单.md`

这些文件共同构成生产规范；不得只看 README 后自行发挥。

## 1. 使命与边界

复用的是**设计系统、工作流、工程参数和 QC 方法**；替换的是用户自己的书目、书目信息、封面版本、个人文字、卷号等变量。

不得把原项目作者的个人阅读记录、序言或第三方封面素材集合直接当作新用户内容。

## 2. 锁定基线

正文工程画布：143 × 208 mm。默认裁切目标：140 × 205 mm。正文默认从004开始；001为“写在前面”，002–003为目录。若目录需要扩页，按《整册结构与页码规则》动态顺延正文。

黄金正文页以 `templates/page/黄金正文页规范.md` 为唯一版式基线。不得为了“更好看”重新设计。

## 3. 输入

最低输入：书名列表。

建议输入：书名、作者、版本/出版社、阅读时间、个人短评、指定封面。

同名作品无法唯一识别时必须询问或 HOLD，不得猜。

## 4. 状态机

### S0｜RECEIVED
收到用户书单。只登记，不直接批量出图。

### S1｜BOOKLIST_CURRENT
执行：去重、同名识别、明显冲突检查、统一编号。生成唯一“权威书目 CURRENT”。

门槛：书目未冻结，不进入整册生产。

### S2｜CONTENT_READY
为每本书建立变量字段。客观书目信息与用户个人文字分开。缺失的个人感想允许留作手写区，禁止 AI 冒充用户编造。

### S3｜COVER_READY
确认每本书所需真实出版封面。AI 生成封面不得冒充真实出版封面。无法可靠确认版本时 HOLD。

### S4｜GOLDEN_SAMPLE_PASS
先选择少量边界样本验证：短标题、长标题、中外文作者、不同封面比例等。按黄金页规范生成。

只有样本 PASS 后才允许批量生产。样本 PASS 后锁定模板，不逐页重新设计。

### S5｜BODY_BATCH
批量生成正文。一书一页为默认规则。每页必须绑定唯一书目 ID 与页码。

局部失败只修局部；已经 PASS 的页面冻结。

### S6｜FRONT_MATTER
正文顺序冻结后制作001和目录。001视觉体系复用，但序言必须属于当前用户。目录从 CURRENT 和最终页码自动生成。

### S7｜COVER_SYSTEM
按外封黄金规范制作正封/封底。保留同一设计语言，同时替换卷号、文字和属于当前用户的阅读元素。

### S8｜ASSEMBLED
合并前置页与正文，生成单一“最终总装候选”。工作稿不得冒充正式打印稿。

### S9｜QC
按 `docs/QC检查清单.md` 检查文件完整性、尺寸、页序、目录映射、奇偶装订侧、页码外侧、残留内容、图片异常和 HOLD。

### S10｜PRINT_READY
只有 HOLD=0，且所有项目 PASS 或已有明确 ACCEPTED DEVIATION，才能标记 PRINT READY。

## 5. HOLD

遇到以下情况停止该项并记录，而不是猜：
- 同名作品无法识别；
- 版本/出版社信息互相冲突；
- 真实封面无法可靠确认；
- 文字超出黄金模板且现有降级规则无法处理；
- 文件/图片损坏；
- 目录与正文页码不一致；
- 必须改变黄金模板才能勉强容纳内容。

HOLD 记录格式：
`编号｜对象｜问题｜影响｜需要用户提供的最小信息｜下一动作`

HOLD 不应阻塞其他互不依赖的条目。

## 6. PASS 与冻结

一项 PASS 后默认冻结。除非上游输入发生变化，不重新搜索、不重新审计、不重新渲染。

ACCEPTED DEVIATION 表示用户明确接受的非阻塞差异；后续不得反复把它重新判为错误。

## 7. 禁止事项

- 不得用 AI 图冒充真实书封。
- 不得为了填满页面虚构用户读后感。
- 不得随意更换出版社、译者或版本。
- 不得新增未经模板允许的装饰、字段、表格或图标。
- 不得因一页异常重跑整册。
- 不得在书目未冻结时制作最终目录。
- 不得在未完成 QC 时称为“正式打印版”。
- 不得为了控制文件大小牺牲必要清晰度；优先分包。

## 8. 最少打扰原则

AI 应自主完成可确定的工作，只在真正需要用户选择/补充时提问。多个 HOLD 尽量汇总一次询问，不要逐页打断用户。

## 9. 交付物

最终至少包含：
- 权威书目 CURRENT
- 001 写在前面
- 最终目录
- 全部正文页
- 正封/封底
- 整册打印候选 PDF
- QC 记录
- HOLD / ACCEPTED DEVIATION 记录（如有）

## 10. 完成定义

成功不是“生成了图片”，而是另一位从未参与原项目的人，只提供自己的已读书单并遵循本仓库，就能在 AI 辅助下稳定完成一本同视觉体系、内容属于自己的、可实际打印的《读书小记》。
