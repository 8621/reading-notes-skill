# 设计规范｜黄金模板基线

> 状态：V0.2。已确认的工程事实先锁定；尚需从最终成品精确测量的参数标为 TODO，禁止猜数值。

## 1. 页面尺寸
- 正文内页：**143 × 208 mm**
- 外封成品基准：**A5 148 × 210 mm**
- 外封印刷：四周 **3 mm 出血**
- 正文采用适合实物书写/阅读的干净米白或奶油纸面视觉，不模拟复古纸纹、泛黄边缘或假纸张阴影。

## 2. 装订与奇偶页
项目采用奇偶页工程意识。右页需考虑左侧装订补偿；页码应处于外侧阅读位置。视觉模板与工程偏移要分开理解：不能为了装订补偿重新发明一套页面设计。

## 3. 黄金模板原则
一个经过验证的正文页作为视觉母板。后续页面的任务是“灌入变量”，不是重新设计。

固定层包括：
- 页面整体网格与留白
- 书封区域
- 书名/作者层级
- 摘要/正文区域
- 页眉、页脚与页码体系
- 装订安全区

变量层包括：
- 书名
- 作者
- 真实书封
- 本书对应文字
- 页码及允许变化的辅助信息

## 4. 边界内容
长书名、长作者名、外文标题等应使用预先定义的降级规则（字号/行数/局部间距），不得临时整体缩放页面或移动所有模块。

## 5. 封面系统
封面与封底属于同一视觉系统，应有明确的“聚/散”或等价叙事关系。新卷可以替换关键元素以区分卷册，但不能变成与正文无关的另一套视觉语言。

## 6. 待精确提取参数
以下参数必须从最终黄金页/工程文件测量后补入，当前禁止凭记忆填数：
- 字体及替代字体
- 各层级字号、行距
- 书封框精确坐标与比例
- 正文文本框坐标
- 页眉/页脚坐标
- 奇偶页精确偏移量
- 图片有效分辨率要求
