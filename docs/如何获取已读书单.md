# 如何获取自己的已读书单

> 这是《读书小记》的真正第 0 步：先把“我读过什么”变成 AI 能整理的数据。

本项目不要求用户手工重新输入几百本书。优先从自己已有的阅读记录、下载历史或导出文件中建立候选书单，再由 AI 去重、确认和生成权威书目 CURRENT。

---

## 路线 A｜豆瓣读书记录

### 目标

把自己在豆瓣标记过的读书记录导出为结构化或半结构化文件，再交给 AI 整理。

原项目曾实际使用电脑端自制导出工具完成这一步，并成功把完整“已读”记录导入项目。

### 推荐数据字段

导出时尽量保留：
- 书名
- 作者
- 阅读状态（读过 / 在读 / 想读）
- 评分（如有）
- 标记日期（如有）
- 用户短评（如有）
- 豆瓣条目链接（如有）

### AI 整理规则

1. 优先处理“读过 / READ”；
2. “在读 / 想读”不要自动混入已读书单；
3. 同一本作品的不同条目先标记，不要直接粗暴删除；
4. 同名作品需要作者等信息消歧；
5. 用户个人短评与 AI 生成文字必须分开；
6. 整理完成后输出 `BOOKLIST_CURRENT`。

### 关于原项目的自制导出插件

原项目确实使用过自制工具导出豆瓣读书记录，但当前公开仓库尚未找到/恢复当时的插件源码。

因此 V0.8 RC **不提供凭记忆重写的“假插件”**。在原源码找回、核对并确认适合公开之前，本仓库只记录已验证的工作流。

未来若恢复源码，将放入：

```text
tools/douban-export/
```

并补充安装、权限、导出格式与隐私说明。

## 路线 B｜Z-Library 下载历史

> 下载历史只能证明“下载过”，不天然等于“读完”。是否把它视为已读，由用户自己决定。

### 原项目实际使用的方法

原项目的下载历史共有 4 页：

```text
50 + 50 + 50 + 5 = 155 条
```

在电脑浏览器中逐页打开自己的下载历史，然后：

1. 每一页使用浏览器 **Ctrl+S**；
2. 保存网页 HTML；
3. 4 页分别保存；
4. 交给 AI 读取；
5. 配套生成的 `xxx_files` 资源文件夹不是书单解析的必要输入，可不提交给 AI。

### 为什么保存 HTML

HTML 中通常已经包含页面显示的书名、作者等文本。相比截图，HTML 更适合 AI/程序批量提取、去重和核对，也避免手工抄录。

### AI 处理流程

```text
下载历史 HTML
      ↓
提取书名 / 作者
      ↓
作品级去重
      ↓
与豆瓣 READ 去重
      ↓
与已有《读书小记》卷册去重
      ↓
得到“下载过但豆瓣可能漏标”的候选
      ↓
按用户自己的阅读判定规则确认
      ↓
BOOKLIST_CURRENT
```

### 阅读判定规则

原项目作者个人采用过：

> “Z-Library 有下载记录 = 默认已读完”

这是**个人工作流规则，不是本 Skill 的通用事实**。

新用户第一次使用时，AI 必须让用户选择：

- **严格模式**：下载记录只算“候选”，用户确认后才进入已读；
- **个人规则模式**：用户明确声明“我的下载记录默认都视为已读”后，AI 才可批量加入。

AI 不得自行假定“下载 = 已读”。

## 路线 C｜手工书单或其他来源

如果没有豆瓣/Z-Library，也完全不影响使用。

用户可以提供：
- TXT / Markdown 书名列表；
- CSV / Excel；
- 其他阅读 App 的合法导出文件；
- 自己整理的笔记；
- 一行一本书的简单文本。

最终都统一进入同一个入口：

`templates/booklist/已读书单模板.md`

---

## 多来源合并

当用户同时提供多个来源时，不要简单拼接。

推荐顺序：

1. 建立豆瓣 READ 主表；
2. 加入其他明确“已读”的记录；
3. 用下载历史补漏；
4. 作品级去重；
5. 同名消歧；
6. 标记来源；
7. 输出唯一 CURRENT。

建议保留一个 `source` 字段，例如：

```text
douban_read
zlibrary_history
manual
other_export
```

这样以后发现错误时，可以追溯“这本书为什么进入书单”。

---

## 隐私提醒

阅读记录可能包含账号昵称、个人评分、短评、时间信息等。

公开 GitHub 项目时：
- 不要提交自己的完整私人阅读历史；
- 不要提交登录 Cookie、Token、密码或浏览器会话；
- HTML 交给 AI 前可先检查是否包含不必要的账号信息；
- 示例数据应脱敏或使用自制样例。

---

## 完成条件

这一步的输出不是最终页面，而是一份可追溯、去重后的：

**权威书目 CURRENT**

只有 CURRENT 冻结后，才进入《读书小记》的内容和视觉生产。
