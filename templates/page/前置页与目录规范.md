# 前置页与目录规范｜V0.4

## 1. 整册结构

已验证的 VOL.01 结构为：
- 001：《写在前面》
- 002–003：目录
- 004 起：一书一页正文

这是一种经过实物生产验证的结构基线。新使用者的书目数量可以变化，因此末页页码不是固定值，但“前置页先占位、正文从004起”的默认结构可复用。

## 2. 001《写在前面》

001 是独立视觉定稿页，不属于普通书目页。

工程基线：
- 143 × 208 mm
- 参考栅格：1430 × 2080 px（约254 ppi）
- 001 为奇数页：左侧为装订侧，页码位于外侧右下

复制项目时，应保留该页的视觉结构，但文案必须改为新使用者自己的项目说明。不得直接把原作者的“写在前面”文字冒充为新使用者的话。

## 3. 002–003 目录

默认两页目录：
- 002：偶数页，装订侧在右，页码位于外侧左下
- 003：奇数页，装订侧在左，页码位于外侧右下

目录必须在正文书目数量和顺序冻结后生成。

## 4. 页码生成

默认：
- 001 = 写在前面
- 002–003 = 目录
- 第一本书 = 004
- 第 n 本书正文页 = n + 3

若书目数量过多导致两页目录无法容纳，应增加目录页，而不是压缩到不可读。此时正文起始页必须整体顺延，并重新计算目录。

## 5. 目录数据源

目录只能从“权威书目 CURRENT + 已冻结正文页码”生成，禁止从旧目录复制后人工零散修改。

生成后至少检查：
1. 书名是否一一对应；
2. 页码是否与正文一致；
3. 是否有漏书/重复；
4. 长书名是否溢出；
5. 002/003 的外侧页码方向是否正确。

## 6. 阶段门

书目 CURRENT 未冻结 → 不做最终目录。
正文页码未冻结 → 目录只能是候选。
目录核对 PASS → 才允许进入最终总装。
