# Agent 自建豆瓣导出工具｜复制指令

> 当你没有现成的豆瓣导出插件时，把下面整段交给自己的 AI Agent。

```text
请帮我制作一个“个人豆瓣读书记录导出工具”。

用途：
整理我自己账号里、正常登录后能够查看的读书记录，供个人《读书小记》使用。

优先使用“浏览器手工保存 HTML → 本地解析”的方案，不要默认开发自动登录爬虫。

输入：
我从浏览器保存的一页或多页豆瓣读书记录 HTML。

尽量提取：
书名、作者、阅读状态（读过/在读/想读）、我的评分、标记日期、我的短评、条目链接。

输出：
1. UTF-8 CSV；
2. JSON 备份；
3. 每本书一条；
4. source=douban；
5. 缺失字段留空，禁止猜测。

要求：
- 支持多 HTML 批量导入与分页合并；
- 条目链接优先去重；没有链接时用“书名+作者”辅助去重；
- 输出成功、重复、失败数量；
- 失败项保留原因；
- 全部默认本机处理；
- 不要求或保存密码、Cookie、Token；
- 不绕过登录、验证码、访问控制或网站技术限制；
- 不凭空假设 DOM，请先检查我实际提供的 HTML；
- 先拿1页做最小测试，通过后再批量处理；
- 最后随机抽查5–10条，与原网页核对。

完成后，请告诉我如何把导出的 CSV/JSON 交给 reading-notes-skill，并进入 BOOKLIST_CURRENT。
```

## 为什么推荐这种方式

网页会改版，固定插件很容易失效；让 Agent 先读取用户当时保存的真实 HTML，再写最小解析器，通常比长期维护一个绑定旧 DOM 的插件更稳。

同时，“保存 HTML → 本地解析”把登录和数据提取分开：用户自己正常登录并保存自己能看到的页面，解析工具不需要持有账号凭据。
