# 外封黄金规范｜V0.4

## 1. 视觉系统

已验证的 VOL.01 外封系统：
- 正封：《阅读残响 · 聚》
- 封底：《阅读残响 · 散》
- 整套名称：《读书小记 · 阅读残响 VOL.01》

核心不是机械复制“VOL.01”文字，而是保留“正封与封底属于同一叙事系统”的设计逻辑。

## 2. 工程基线

- 正封/封底单页基准：A5 148 × 210 mm
- 印刷需考虑四周 3 mm 出血
- 外封与内页应保持同一纸张/色调体系
- 数字文件保持干净平面，不人为模拟泛黄、纸边阴影、压痕或假书脊质感

## 3. 聚 / 散关系

“聚”承担正封的视觉聚合与识别；“散”承担封底的呼应与释放。两面应让人一眼看出属于同一本书，而不是两张互不相关的海报。

新使用者可以：
- 修改卷号
- 修改属于自己的标题/副标题
- 替换与其书目相关的合法视觉元素
- 在保持体系的前提下做有限差异化

不得：
- 只留下图片而丢失原有“书籍文字/阅读痕迹”语言
- 每一卷重新发明完全不同的封面风格
- 直接复制原项目的个人化书单元素冒充自己的阅读记录

## 4. 外封生产原则

外封是独立输出层，不反向修改已经 PASS 的正文母版。

若采用骑马钉/包封等不同装订方式，书脊、拼版和 creep 等工程问题在最终输出层解决。

## 5. AI 检查

生成外封候选后检查：
- 正封/封底是否明显属于同一系统
- 标题与卷号是否清楚
- 是否保留“阅读/书籍”核心视觉语言
- 实际缩小到打印尺寸后文字是否仍可读
- 出血与安全区是否满足输出方式
- 是否误用了无授权或不应重新分发的第三方资产

## 6. 公开仓库注意

本 GitHub 项目公开的是设计规则和可复用模板结构，不把第三方出版物封面集合打包成素材库。示例资产需要单独判断版权与公开许可。
