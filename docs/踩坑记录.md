# 踩坑记录｜真实生产经验

> 目的不是记录“犯过什么错”，而是把错误转化成下一位使用者和 AI 不再重复的永久规则。

## 01｜不要边改书单边做最终目录
**问题：**正文数量/顺序变化会导致目录页码整体漂移。  
**修正：**先冻结权威书目 CURRENT，再生产正文；正文冻结后才做最终目录。  
**永久规则：**目录属于后置生产项。

## 02｜不要把“找到一张封面图”当成“版本已确认”
**问题：**同名书、不同译本/出版社、再版封面很容易混淆。  
**修正：**优先确认真实出版版本；不能可靠确认则 HOLD。  
**永久规则：**AI 生成图绝不能冒充真实出版封面。

## 03｜不要因为局部错误重跑整册
**问题：**整册重做会引入新的错位、内容回退和大量重复劳动。  
**修正：**页级定位、页级修复；PASS 页面冻结。  
**永久规则：**最小修改面原则。

## 04｜旧内容可能残留在新页面
**问题：**复用模板时，旧页脚、旧文字或上一页内容可能残留。  
**修正：**模板中明确变量层；生产后检查残片。  
**永久规则：**新内容写入前先清空所有变量字段。

## 05｜页码正确不等于装订后好读
**问题：**屏幕居中看起来正常，装订后内侧可能被吃掉。  
**修正：**区分视觉模板与奇偶页工程偏移，保留装订安全区。  
**永久规则：**印刷版必须按实际装订方向检查。

## 06｜屏幕效果不能代替实物样张
**问题：**纸张颜色、字号体感、图片对比度和装订边距在屏幕上无法完全判断。  
**修正：**保留实物打印照片与样张反馈，并反向修订规范。  
**永久规则：**重要版本在条件允许时进行实物验证。

## 07｜已经 PASS 的内容不要反复审计
**问题：**重复核验浪费时间，还可能把已确认的例外重新判错。  
**修正：**使用 PASS / HOLD / ACCEPTED DEVIATION 状态。  
**永久规则：**除非上游输入发生变化，否则冻结项不重做。

## 08｜工作稿与正式打印稿必须分开
**问题：**文件多时很容易把候选稿发给打印店。  
**修正：**正式交付使用明确文件名和独立目录。  
**永久规则：**只有完成最终 QC 的文件才允许标记 PRINT READY。
