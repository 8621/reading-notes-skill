# 版权与素材边界

本项目的目标是公开“制作方法与自有设计规则”，不是重新分发第三方出版物素材库。

## 可以公开
- 本项目原创的流程、文字说明和 QC 方法；
- 自制模板结构与工程参数；
- 经项目作者确认可公开的实物照片；
- 自制或获得许可的示例素材。

## 默认不随仓库重新分发
- 第三方书籍封面批量素材；
- 书籍正文、长篇摘录或扫描内容；
- 出版社/作者拥有版权但未取得再分发许可的素材；
- 含不必要个人信息的照片或文件。

## 用户自己制作时
用户可以向自己的 AI 提供其合法持有或可使用的书籍信息与参考材料。AI 应按适用法律、平台规则及素材许可处理，不应把“个人制作中可参考”自动理解成“可以重新打包公开发布”。

## 实物照片
后续加入原版《读书小记》的实物打印照片前，应检查：
- 是否含可识别个人信息；
- 是否含无关私人环境；
- 是否需要裁切；
- 图片中的第三方书封是否只是用于说明整体实物效果，而非作为可下载素材库提供。

本文件只定义项目仓库的素材边界，不替代法律意见。
