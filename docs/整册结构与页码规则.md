# 整册结构与页码规则｜V0.4

## 默认结构

```text
001  写在前面
002  目录（一）
003  目录（二）
004  第1本书
005  第2本书
...
```

默认“一本书 = 一页”。

## 动态页数

若共有 N 本书，在两页目录足够的前提下：
- 正文页数 = N
- 内页总页数 = N + 3
- 最后一页页码 = N + 3

例如原 VOL.01 有 117 个正文书目单元，因此 004–120 正好 117 页，全册为 120 页。

## 目录扩容

如果 N 较大、书名较长或目录版面无法保持可读性，允许增加目录页。目录页数记为 D，则：
- 正文起始页 = 2 + D
- 第1本书页码 = 2 + D
- 第 n 本书页码 = n + 1 + D
- 总页数 = 1 + D + N

页码变化必须由程序/AI统一计算，禁止手工逐条补丁式改号。

## 奇偶页

奇数页：装订侧在左，页码在外侧右。
偶数页：装订侧在右，页码在外侧左。

最终拼版方式可以改变，但不得破坏成品阅读状态下的这个逻辑。

## 总装阶段门

只有以下全部成立才能生成“最终总装候选”：
- 001 PASS
- 目录 PASS
- 正文全部 PASS / 已记录 ACCEPTED DEVIATION
- HOLD = 0
- 页码映射冻结

总装完成后只做结构/工程检查，不借总装之名重新改写已经冻结的页面内容。
